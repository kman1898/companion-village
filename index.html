Can't reach Companion?

This page is served over https, but Companion speaks plain http. Browsers protect you from secure pages talking to insecure local devices, so it depends on the browser:

  • Chrome / Edge: works. Allow the “access devices on your local network” prompt. Use an IP address (e.g. 192.168.1.20:8000) or a .local name.
  • Companion on this computer (localhost): works in Chrome, Edge and Firefox.
  • Safari, Firefox to another machine, OBS browser source: usually blocked.

Always works: download the offline copy (Settings → ⬇ Offline copy) and open that file directly, or use it as an OBS Local file browser source. It is the same app in a single file.
